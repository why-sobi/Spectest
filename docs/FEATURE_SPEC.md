# Calculator Feature Specification

Module: `src/calculator.py`

## add(a, b)
- Returns the sum of `a` and `b`.
- Works with negative numbers and floats.

## subtract(a, b)
- Returns `a - b`.

## multiply(a, b)
- Returns the product of `a` and `b`.
- Multiplying by zero returns 0.

## divide(a, b)
- Returns `a / b` as a float.
- Dividing by zero raises `ZeroDivisionError`.
